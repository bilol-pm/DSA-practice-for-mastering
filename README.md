# 🎬 Cinema Queue Simulation (Python DSA)

A simple Python console application demonstrating the **Queue (FIFO - First In, First Out)** data structure using Object-Oriented Programming (OOP) and real-time simulation (`time` module).

## 🚀 Features
- **OOP Approach:** Uses a `Cinema` class to manage customers and the queue.
- **Queue Operations:** Implements `enqueue` (adding to the line) and `dequeue` (`pop(0)` for serving customers).
- **Real-time Simulation:** Uses `time.sleep(5)` to simulate actual waiting time at a cinema ticket counter.
- **Dynamic Updates:** Automatically recalculates and updates the user's position in the queue as people ahead of them get served.

## 💻 Technologies Used
- Python 3.x
- Data Structures: Queue (Lists)
- Modules: `time`
